## 📌 Sobre o Projeto

Este repositório foi desenvolvido para fins estritamente educacionais como parte do desafio final de sprint do semestre. 

O **Biblioteca Musical** é uma aplicação web projetada para cadastrar e gerenciar um acervo de música, organizando:
* **Artistas**
* **Álbuns**
* **Músicas**

A interface permite visualizar todo o conteúdo cadastrado de forma simples e estruturada em listas.

---

## 🛠️ Tecnologias Utilizadas

O projeto utiliza as seguintes tecnologias front-end:

* **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML)** — Estruturação do conteúdo e elementos semânticos da página.
* **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS)** — Estilização, layout e responsividade visual.
* **[Git](https://git-scm.com/) & [GitHub](https://github.com/)** — Controle de versão e hospedagem do código-fonte.
